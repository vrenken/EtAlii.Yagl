# .NET / C# Contributing Guidelines

When writing unit tests for this project, you must follow the **Arrange/Act/Assert (AAA)** pattern:

- **Arrange**: Set up the necessary preconditions and inputs.
- **Act**: Perform the action or operation being tested.
- **Assert**: Verify that the expected outcome occurred.

When creating C# test files, you must always name them `[TYPE].Tests.cs`.
